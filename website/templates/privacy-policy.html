Privacy

How this static open-source project website handles visitor information.

Last updated: {{ last_updated }}

This is the static documentation website for HarborRAG, an open-source project. The site itself does not operate user accounts, advertising, or application telemetry.

Hosting and external services

The hosting provider may process standard request information such as IP addresses, browser details, requested paths, and timestamps for security and service operation. Links to GitHub and other third-party services are governed by those services’ policies.

Cookies and local storage

The generated HarborRAG website does not intentionally set tracking cookies. Coverage artifacts or externally hosted pages may have separate behavior.

Documentation feedback

If you open an issue, the content and account information you submit become part of the repository’s public issue history unless GitHub or a repository maintainer removes them.

Questions

Use the HarborRAG issue tracker for privacy or documentation questions.
