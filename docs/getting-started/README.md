# Getting Started

Start with the [Quick Start](quick-start.md) to get your first cited answer in about
half an hour. You'll run HarborRAG locally in Docker and ask a question about the
repository's documentation.

HarborRAG is an alpha retrieval-augmented generation (RAG) framework for engineering
knowledge. It indexes documents from your team's tools and grounds answers in the
current versions of those documents.

## What the Quick Start asks you to set

The Quick Start creates an `env/` folder. You'll configure the model endpoint, enable
the PostgreSQL URL for the CLI, and back up the key that encrypts stored connection
credentials. [Quick Start step 2](quick-start.md#2-create-the-environment-files) shows
the exact edits.
